# Ziyodulla Otabayev — Portfolio

Personal portfolio website built with pure HTML, CSS, and JavaScript.

**Live site:** https://ziyodullaotabaev.github.io/portfolio

## Tech Stack
- HTML5
- CSS3 (Custom dark theme, animations)
- Vanilla JavaScript

## Features
- Dark minimal design
- Responsive (mobile, tablet, desktop)
- Scroll animations
- Download CV (print to PDF)
- Real-time Tashkent clock
- Profile photo with animated ring
- GitHub Pages deployment

## Local Development
Just open `index.html` in your browser — no build tools needed.
